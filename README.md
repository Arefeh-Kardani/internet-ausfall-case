# Internetausfälle dokumentieren

Eine einfache, statische Website (reines HTML/CSS, kein Framework), die
unsere Erfahrung mit wiederkehrenden Internetausfällen in Deutschland
dokumentiert und anderen Betroffenen als Hilfestellung dienen soll:

- Wie man Ausfälle dokumentiert (Breitbandmessung / Messprotokoll)
- Wie man den Internetanbieter kontaktiert
- Wie eine außerordentliche Kündigung wegen anhaltender Störungen
  begründet werden kann
- Vorlagen für Kündigung und ein Ausfall-Log (im Ordner `/templates`, direkt von den jeweiligen Seiten verlinkt)
