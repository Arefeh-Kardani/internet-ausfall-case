# Screenshots &amp; Nachweise

Legt hier eure **anonymisierten** Screenshots und Nachweis-Dateien ab
(z.B. Messprotokoll-Auszüge, Router-Fehlermeldungen, Provider-Chat
ohne persönliche Daten).

## Vor dem Hochladen unbedingt prüfen

Entfernt bzw. schwärzt in jedem Bild/Dokument:

- Vor- und Nachname
- Adresse
- Kunden- und Vertragsnummer
- Telefonnummer, E-Mail-Adresse
- IP-Adresse, MAC-Adresse, Seriennummern
- Router-/WLAN-Namen (SSID), falls der Wohnort dadurch erkennbar wäre
- Jede andere Angabe, die euch oder Dritte identifizierbar macht

## Empfohlene Dateinamen

Verwendet sprechende, anonyme Dateinamen, zum Beispiel:

```
messprotokoll-2026-03-beispiel.png
ausfall-fehlermeldung-beispiel.png
```

## Einbinden in die Seiten

```html
<img src="assets/screenshots/dateiname.png" alt="Kurze, anonyme Beschreibung des Bildes">
```

Diese Datei selbst ist nur ein Platzhalter/Anleitung und enthält keine
echten Bilder.
